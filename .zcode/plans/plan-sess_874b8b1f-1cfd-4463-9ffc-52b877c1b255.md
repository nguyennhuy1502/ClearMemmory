
# Kế hoạch: Làm lại UI + Thêm tính năng tối ưu + Tạo file cài

## 1. Modern Theme (sv_ttk)
- Cài `sv_ttk` + `darkdetect` — Windows 11 Sun Valley style, tự nhận theme OS
- Thay thế theme hiện tại (vista/clam cũ) bằng sv_ttk

## 2. Redesign Giao diện (`cleaner.py` — viết lại hoàn toàn)

### Cấu trúc mới — 4 tab, layout chuyên nghiệp:

**Tab 1: 🏠 Tổng quan (Dashboard) — MỚI**
- Thẻ hệ thống: Disk free/total, RAM used/total, CPU%, số startup items
- Nút SCAN lớn ở giữa + tổng dung lượng rác tìm được
- Nút CLEAN ALL one-click
- Lần quét cuối, tổng đã dọn

**Tab 2: 🧹 Dọn rác (Cleaner) — giữ logic cũ, UI mới**
- Bảng Treeview giữ nguyên 5 cột (check, category, size, files, status)
- Click toggle chọn/bỏ chọn (giữ)
- Double-click mở chi tiết tệp (giữ)
- Panel bên phải preview + nút xem chi tiết (giữ)
- Nút: Quét lại / Dọn đã chọn / Chọn tất cả / Bỏ chọn

**Tab 3: ⚡ Tối ưu (Optimize) — NÂNG CẤP MỚI**
- Dashboard RAM/CPU realtime với thanh progress visual
- Top processes table (giữ từ optimizer.py)
- **MỚI: Startup Manager** — liệt kê + toggle enable/disable mục startup (registry HKCU/HKLM Run)
- **MỚI: Disk Analysis** — top 10 thư mục/người dùng ngốn dung lượng nhất
- **MỚI: System Tweaks** — các đề xuất tối ưu:
  - Tắt/indexing service giảm I/O disk
  - Tắt Services không cần thiết
  - Tắt visual effects (Performance Options)
  - Tắt transparency
  - Power plan: High Performance
- Nút hành động: Free RAM, Restart Explorer, Clear Clipboard (giữ cũ)

**Tab 4: 🛡️ Bảo mật (Security) — giữ logic cũ**
- Giữ nguyên 28 security checks
- UI mới: card-based layout thay vì treeview + text

### Thanh toolbar trên cùng:
- Logo + tên app (trái)
- Nút: Scan | Clean | Run as Admin | VI/EN | About (phải)

### Footer:
- Status bar + progress bar (giữ)

### File chi tiết tệp:
- Double-click category → popup Toplevel riêng (không phải tab nữa)
- Popup có filter, open in Explorer, close

## 3. Nâng cấp `optimizer.py`
Giữ nguyên các hàm cũ + thêm:
- `startup_items()` → list startup registry items (name, value, hive, enabled)
- `toggle_startup(name, hive, enable)` → enable/disable mục startup
- `disk_usage_top(n)` → top thư mục ngốn dung lượng (user profile)
- `system_tweaks()` → list đề xuất tweak + fn thực thi
- Tweaks: disable_indexing, disable_superfetch, set_power_plan, disable_transparency, disable_visual_effects
