**3. Privacy/Telemetry tweaks (MỚI — thêm vào hoặc hàm riêng)**
- Cortana: HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search → AllowCortana=0
- Telemetry: HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection → AllowTelemetry=0
- Advertising ID: HKCU\...\AdvertisingPlatform\Enabled=0
- Input Personalization: HKCU\SOFTWARE\Microsoft\InputPersonalization → AcceptedPrivacyPolicy=0, RestrictImplicitTextCollection=1
Mỗi tweak có `is_applied()` check + `fn()` apply, cấu trúc giống suggested_tweaks hiện có.

**4. Disk (MỚI)**
```python

```

**Bảo mật**: tất cả subprocess dùng list form (no shell=True), service name qua `_is_safe_service_name()` style check trước khi gọi `sc`. winreg dùng đúng access mask (`KEY_ALL_ACCESS | KEY_WOW64_64KEY`).

## D. Thứ tự thực hiện (incremental)

1. **optimizer.py**: thêm các hàm mới (Service/Network/Privacy/Disk). ~+250 dòng.
2. **test_optimizer.py** (mới, nhỏ ~10 test): verify hàm mới chạy được, không exception.
3. **cleaner.py**: viết lại hoàn toàn với sidebar layout + page Tối ưu 5 section.

5. **installer.iss**: fix `LicenseFile=` rỗng.
6. **build_installer.py**: tạo script 1-lệnh build setup.exe.
7. **build.py**: chạy → `dist/Cleaner.exe`.
8. (Nếu có ISCC) **build_installer.py** → `installer_output/Setup_ClearMemmory.exe`.
9. Chạy test_core + test_security + test_attacks → ensure 0 regress.
10. Commit + push GitHub.
