## Kế hoạch triển khai — Deep System Cleaner (Dọn rác chuyên sâu)

### Tệp sẽ tạo
1. **`categories.py`** — Registry phân loại rác: mỗi category có `id, tên VN/EN, root(), matcher (file/dir patterns), mô tả, cờ needs_admin, cờ command (flush DNS)`. Bao gồm ~14 mục: Temp User, INetCache, Thumbnail cache, IconCache.db, CrashDumps, WER-user, Cache 5 trình duyệt (Chrome/Edge/Firefox/Cốc Cốc/Brave — chỉ Cache/Code Cache/GPUCache), Temp Windows, WER-system, Minidump+MEMORY.DMP, Windows Logs/Panther, Recycle Bin (all drives), Flush DNS.

2. **`core.py`** — Engine thuần:
   - `format_size(bytes)` → KB/MB/GB.
   - `safe_join_under(root, *parts)` + `is_within(path, root)` — path guard.
   - `scan_category(cat)` → (danh sách tệp/thư mục ứng viên, tổng size, số tệp) bằng `os.scandir` đệ quy, bỏ qua lỗi quyền.
   - `clean_category(cat, candidates)` → (cleaned_bytes, removed_count, skipped_count) — xóa per-file, catch PermissionError.
   - `empty_recycle_bin()`, `flush_dns()` qua ctypes/subprocess.
   - Worker dùng `threading.Thread` + callback qua `root.after`.

3. **`cleaner.py`** — UI tkinter + main:
   - Kiểm tra admin (ctypes `IsUserAnAdmin`), banner nâng quyền.
   - Treeview bảng: cột [✓, Category, Size, Files, Status], click dòng toggle chọn.
   - Nút: Quét lại / Dọn rác đã chọn / Chạy quyền Admin.
   - Thanh tiến trình + nhãn trạng thái song ngữ.
   - Bảng kết quả "rác đã dọn" với tổng đã giải phóng & tổng bỏ qua.
   - Logging lỗi ra `cleaner_error.log` (phòng pythonw crash).

4. **`run.bat`** — `pythonw cleaner.py`, chạy trong thư mục script, click đôi là mở UI.

5. **`test_core.py`** — Test logic thuần (path guard, format_size, scan/clean trong tempfile).

6. **`README.md`** — Hướng dẫn cài/đặt/chạy, danh sách mục dọn, lưu ý an toàn.

### Thứ tự làm
1. `categories.py` → 2. `core.py` → 3. `test_core.py` + chạy test → 4. `cleaner.py` (UI) → 5. `run.bat` + `README.md` → 6. Chạy thử SCAN để xác minh UI & số liệu (không dọn thật).

### Xác minh
- `python test_core.py` pass.
- Khởi động UI qua `run.bat`, bấm Quét → bảng hiện dung lượng/số tệp; bấm Dọn → bảng kết quả hiện rác đã dọn (với tệp đang khóa được báo "bỏ qua").
- Số liệu tổng hợp đúng.
